# Event Standard Operating Procedure

## Before an Event

Verify:

1. Room assignment
2. Room capacity
3. Assigned staff
4. Assigned vendors
5. Required equipment
6. Known incidents

## Operational Conflicts

A double-booked room must not be used until the conflict is resolved.

A replacement room must satisfy the event's capacity and scheduling requirements.

## Incident Handling

Every incident should be:

1. detected
2. analyzed
3. assigned an impact
4. given one or more candidate response plans
5. simulated before execution
6. approved by an authorized human
7. executed
8. verified

## Human Approval

Operational changes must not be executed solely because an automated system proposed them.

An authorized human must explicitly approve the selected plan before execution.
