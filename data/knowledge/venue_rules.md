# Venue Rules

## Room Capacity

A room must not be used when expected occupancy exceeds its rated capacity.

The expected occupancy for an event is the larger of the planned attendance and a reliable observed occupancy signal.

If observed occupancy exceeds room capacity, the event should be relocated to a suitable room before the event continues.

## Room Assignment

A room is suitable only when:

- the room status is AVAILABLE
- room capacity meets the required occupancy
- no active reservation overlaps the requested event interval
